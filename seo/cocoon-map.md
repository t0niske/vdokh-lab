## Спрос (наблюдение: подсказки Яндекс lr=163 и Google gl=kz, 29.10.2026)
- Коммерческое ядро: «ароматизация помещений [астана | цена | оборудование | для бизнеса | профессиональная | коммерческих помещений]», «аромамаркетинг [астана | для бизнеса]».
- По форматам: «ароматизация офиса / магазина / ресторана / в отелях», «аромамаркетинг в ресторане / для кофейни».
- Технология: «ароматизация через вентиляцию», «ароматизатор в вентиляцию», «диффузор для ароматизации помещения», «аромадиффузор как работает / для офиса».
- Информационное: «аромамаркетинг это / что это / примеры», «аромадиффузор вред / вред для здоровья / опасен для кошек», «аромамасло для диффузора / как разбавить».
- Вне границ (negative intents): химия «ароматизация алканов/тестостерона», авто, кроссовки, табак, самогон; бытовые «аромадиффузор фикс прайс / вайлдберриз / своими руками».

## Разведение каннибализации (M16)
- `/` vs `/pomeshcheniya/`: главная — «ароматизация помещений для бизнеса в Астане», хаб — «по типу помещения» (title и H1 изменены 29.10.2026).
- `/pomeshcheniya/zhk-podezd/` vs `/osi/`: ЖК — лобби и лифтовые холлы для девелопера/УК; ОСИ — подъезды по договору с ОСИ. Title/H1 разведены.
- `/kak-my-rabotaem/` (как работаем мы, сервис) vs `/stati/aromatizaciya-cherez-ventilyaciyu/` (сравнение способов подачи, плюсы и минусы, кому не подходит).
- `/stati/aromatizaciya-cherez-ventilyaciyu/` (как устроено, плюсы и минусы, 3 способа) vs `/stati/vidy-diffuzorov-dlya-pomeshchenij/` (типы аппаратов) vs `/stati/ventilyaciya-ili-nastennyj/` (выбор по помещению: проверка вентиляции за 10 минут, разбор 6 ситуаций, когда лучше настенный). Под статьёй — 4 похожие (3 из раздела + опорные), не все 16 (30.10.2026).
- `/ceny/` (наш прайс) vs `/stati/skolko-stoit-aromatizaciya/` (из чего складывается цена, покупка vs подписка, порог окупаемости).
- `/pomeshcheniya/restoran-kafe/` vs `/stati/aromamarketing-v-restorane-i-kofejne/` (решение vs как не помешать кухне, исследование).
- `/pomeshcheniya/magaziny/` vs `/stati/aromatizaciya-magazina-odezhdy/` (решение vs выбор аромата под стиль одежды).

## Перелинковка (сделано)
- Каждая статья ссылается на 1–3 страницы услуг по следующему шагу (анкоры по задаче: «как рассчитать ароматизацию», «ароматизация магазинов и шоурумов»).
- Опорная статья → примеры, исследования, через вентиляцию, проверка эффекта, выбор аромата.
- Страницы пространств → блог пока не ссылаются (следующий шаг: блок «Читать по теме» на 2–3 статьи).
