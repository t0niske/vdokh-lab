# ВДОХ lab — ароматизация помещений на плане

Смелый формат сети: вместо квиза — тепловизор аромата. План помещения сверху, диффузоры ставятся кликом, аромат расходится в реальном времени: обходит стены, проходит в двери. Справа — процент покрытия, аппараты и цена подписки.

Сайт: https://t0niske.github.io/vdokh-lab/

## Структура (20 страниц)
- `/` — симулятор с 6 планами
- `/simulyator/` + кофейня, бутик, офис, клиника, отель, фитнес — у каждого плана свой текст про расстановку
- `/zapahi/` + 6 страниц «как убрать запах» (санузел, кухня, табак, животные, мусор, пот)
- `/raschet/` — калькулятор: площадь, потолки, закрытые комнаты
- `/kak-rabotaet/`, `/kontakty/`

Запросы — информационные («где поставить ароматизатор», «как убрать запах», «сколько ароматизаторов нужно»), чтобы не пересекаться с Tynys.

## Как это устроено
- Планы — `src/scenes.js` (размеры в метрах, стены, мебель, зоны, расстановка по умолчанию).
- Симулятор — `src/assets/js/sim.js`: сетка 0,25 м, геодезическое расстояние (Дейкстра), концентрация `exp(-1.2·(d/R)²)`, R = √(1,4·A/π) для паспортной площади A.
- Тексты — `src/pages.js`, `src/odors.js`; картинки и промпты — `IMAGES.md`.

```
node build.js
```
