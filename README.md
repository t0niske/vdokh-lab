# ВДОХ — симулятор аромата

Смелый формат вместо обычного лендинга: интерактивный симулятор. Посетитель выбирает своё пространство (бутик, отель, кофейня, фитнес, клиника, офис), нажимает на зоны на изометрической схеме и видит, как облако аромата заполняет помещение. Внизу — площадь, срок, подобранные аппараты и цена в месяц, а «сцену» можно отправить в WhatsApp.

**Сайт:** https://t0niske.github.io/vdokh-lab/

## Что на странице
- Симулятор на весь экран: 6 пространств, по 4 зоны в каждом (задача → решение), реплики гостей, пиксельный переход между сценами
- Облако аромата меняет цвет по категории аромата и размер по площади, числу аппаратов и интенсивности
- Консоль: площадь, срок подписки, набор Nova 300 / Nova 1000, покрытие, цена в месяц
- Ниже: протокол работы, оборудование, библиотека 32 ароматов, факты, FAQ, контакты

## Как менять данные
- Цены, ароматы, контакты — `js/data.js`
- Пространства, мебель, зоны и реплики — `js/scenes.js` (комната 10×10 единиц, координаты x/y/z)

## Структура
`index.html` · `css/style.css` · `js/data.js` · `js/scenes.js` · `js/led.js` · `js/main.js`.
