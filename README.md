# Aromé — устранение запахов и ароматизация помещений

Для тех, у кого пахнет неприятно: ставим свой аппарат и заправляем маслом — он нейтрализует запах и наполняет помещение ароматом. Ничего не ищем и не ремонтируем; подписка на аппарат, масла и обслуживание, установка в день обращения, первые 3 дня бесплатно. Tynys отвечает на «хочу, чтобы пахло приятно», Aromé — на «пахнет плохо, что делать».

Сайт: https://t0niske.github.io/vdokh-lab/ · стратегия — документ «Стратегия сайтов», вкладка Aromé.

## Для кого
Кафе и рестораны, тойханы, ОСИ и УК (подъезды), фитнес и раздевалки, клиники и ветклиники, салоны красоты, туалеты ТРЦ и АЗС, офисы, гостиницы, квартиры.

## Структура (37 страниц + 3 переадресации)
- `/` — первый экран по референсу Beautica (полоса-анонс, терракотовая шапка, два фото — санузел ТРЦ и зал кафе, вордмарк AROMÉ вне H1), подбор «где пахнет → чем пахнет → что сделает аппарат, где поставим, цена», 12 запахов, как работает аппарат, сравнение аэрозоль / озон / Aromé, подписка, как начать, вопросы, заявка

- `/nejtralizator-zapaha/`, `/osi/` (цена за подъезд, договор и акт, объявление для собрания жильцов), `/kvartira/`

## Как это устроено
- Тексты: `src/odors.js`, `src/places.js`, `src/articles.js`, `src/texts.js`; страницы — `src/pages.js`, блоки — `src/ui.js`, иконки — `src/icons.js`.
- **`src/config.js` — поля для владельца:** свои телефон, WhatsApp и адрес (пустые — берутся общие из `lib/data.js`), что делает масло с запахом, условия теста, номера счётчиков Метрики и GA4.
- WhatsApp везде с меткой «Пишу с сайта Aromé, страница «…»». Форма заявки — где пахнет, площадь, телефон, галочка теста.
- Аналитика (`src/assets/js/main.js`): события `wa_click`, `call_click`, `form_submit`, `test_request`, `osi_template` → `dataLayer`, Метрика и GA4, когда заполнены номера.
- Объявление для ОСИ `src/assets/osi-obyavlenie.txt` генерирует `build.js`.
- Картинки и промпты — `src/images.js` → `IMAGES.md`, файлы — `src/assets/img/<ключ>.webp`.

```
node build.js
```
