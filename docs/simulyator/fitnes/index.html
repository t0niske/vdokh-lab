// расстановка

Где ставить диффузор

  1. Тренажёрный зал закрывает один Nova 1000 в центре зала, например на колонне: от стены он не дотянется до дальних углов.
  2. Раздевалки за стенами и дверями — отдельная история. В каждую нужен свой аппарат.
  3. Для зала выбирайте свежие композиции: морские, цитрусовые, эвкалипт. Они не тяжелеют при нагрузке.
  4. Ресепшн получает аромат из зала, если между ними нет стены.

Вопросы

Сколько диффузоров нужно фитнес-клубу 900 м²?

Обычно один Nova 1000 на зал и по одному Nova 300 в каждую раздевалку.

Справится ли аромат с запахом пота?

Вместе с вентиляцией — да. В раздевалках нужен отдельный аппарат со свежим ароматом.

Какие ароматы подходят для фитнеса?

Морской бриз, Ocean, Эвкалипт, Свежий цитрус.
