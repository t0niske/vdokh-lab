// расстановка

Где ставить диффузор

  1. В open space аромат расходится свободно: один аппарат у стены закрывает большую часть зала.
  2. Переговорные с закрытыми дверями получают меньше аромата. Если двери обычно закрыты, нужна отдельная точка.
  3. Аппарат рядом с кухней перекрывает запах обеда, пока он не разошёлся по этажу.
  4. Включайте диффузор по расписанию: к началу рабочего дня и с паузами.

Вопросы

Сколько диффузоров нужно на офис 280 м²?

Обычно два Nova 300: один на open space, второй — у кухни или в зоне переговорных.

Не будет ли аромат мешать работать?

Нет, если интенсивность низкая и диффузор работает по расписанию. Для офиса выбирают свежие и чайные ароматы.

Проходит ли аромат сквозь стены?

Нет. Он проходит через двери и проёмы, поэтому закрытым кабинетам нужны свои точки.
